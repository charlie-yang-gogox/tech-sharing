THE POST · 原文的圖
（原文第 3 格 · worker → verifiers）
原文怎麼定義這個 PATTERN
“For each spawned agent, run a separate spawned agent to adversarially verify its output against a rubric or criteria.”
GGC · 我們實際的接法（同構畫法）
我們用到這個 PATTERN 的哪一段
  • 對到的部分：separate spawned agent — 實作者永遠不稽核自己的 diff；以及 against a rubric —「只動到 UI 嗎」「行為變了嗎」就是那份標準。
  • 我們把 N 固定成 2，但兩位釘在不同 model tier，為的是漏判不相關；兩者都 CLEAR 才過，任一 BLOCK 整個 diff 退回。
  • 我們加的一條：稽核者不准讀實作者整理過的摘要，只讀原始 payload — 讀了摘要就會繼承同一個盲點。
  • 而且驗的是宣稱不只是 code：worker 可以什麼都沒出貨還回報 done，所以 evidence phase 有三個結果 — confirmed / missing / inconclusive。

跟現在的畫法差在哪：現在六張 GGC 圖各畫各的（有的由上往下、有的顏色自己選、agent 有時是圓有時是方）。同構之後，六張圖跟地圖用同一套視覺文法，觀眾一眼就接得回去。
